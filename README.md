# WHAT AI THINKS

**AI knows what you really mean.**  
Turn any thought, feeling, question, or random idea into a witty comic.

A fun **vibe-coding** experiment.

---

## 🎯 What is this?

- Type any thought (Chinese or English)
- Click **RUN**
- AI automatically chooses the best comic style and generates:
  - A funny comic image
  - Insightful English + Chinese interpretation

**Tagline**: *Enter the void of human consciousness*
